## 1. 大譜表の下の五線のトリルの線が、上の五線の下の声部の連桁を横切る

再現: **`docs/repro/trillspan-grandstaff-gap-2026-10-20.lys`**（生成譜 piano003 そのもの）。

**症状**: 4 小節目、左手の `<cis eis>8@startTrillSpan` から 5 小節目の `ais,,16@stopTrillSpan` までの線が、2 つの五線の間に描かれ、波が右手の下の声部の 16 分音符の連桁の中をまっすぐ通る。
同じ形が piano007 の 7〜8 小節にもある（`out/gen-trill-s11/piano/piano007/piano007.lys`。波が右手の下の声部の連桁と 8 分音符の旗を横切る）。

**LilyPond 2.26.0**: 線は右手の下の声部の連桁より下、左手の五線の上に収まり、そのぶん 2 つの五線の間が広がる。

**見立て**: 前回 `78164829a` で直したオッターヴァの線（大譜表の下の五線の線が譜表の間隔に数えられない）と同じ型に見える。トリルの線も五線の間隔の計算に入っていないのでは。

**再現の条件**: 4〜5 小節だけを抜き出した 2 小節の譜では再現しない（五線の間が十分に空く）。曲全体で、ページに段を詰めたときに起きる。

**OMR への害**: 波を連桁のところで見失い、線の始まりも終わりも読めない。残りの波はプラル（`@prall`）と読んでしまう。

## 2. 段と段の間隔がトリルの線を数えない

再現: **`docs/repro/trillspan-system-gap-2026-10-20.lys`**（生成譜 ledger002 そのもの、ヘ音記号の 1 段の譜）。

**症状**:
- 16 小節目（最後の段）: 加線 3 本の上の `a8@startTrillSpan` の「tr」と波が、上の段の 13 小節目の、五線の下にぶら下がる低い音（加線の上の `ais,,,16`）の中に描かれる。
- 7 小節目（4 段目の頭）: その段の線が、上の段の 5 小節目の低い音（五線の下の `b,,,8.`）を横切る。

**LilyPond 2.26.0**: 同じ段の切れ目で、どちらの線も上の段の音に触れないように段の間を空ける。

**見立て**: 1 と同じく、トリルの線が段の上下の輪郭（段と段の間隔を決めるもの）に入っていないのでは。1 と根が同じなら、1 つの直しで両方直るかもしれない。

**OMR への害**: 「tr」が上の段の音符と重なり、検出器が「tr」を見ない。線が丸ごと読めない。

## 3. オッターヴァの線の外の、同じ音の臨時記号（前に書いて、まだ送っていなかったもの）

再現: **`docs/repro/ottava-accidental-after-line-2026-10-20.lys`**

```lys
octave absolute
time 4/4
key g major

part p1 { clef bass }

section Piece {
  p1 {
    fis,,,16@ottava(bassa) ges,,,16 c,,,16 c,,,16 ges,,,8@!ottava r8 r2 |
  }
}

form { ~Piece }

score {
  staff p1 "Staff"
}
```

**症状**: 8vb の線の下の `ges,,,16` は G2 の位置に ♭ つきで描かれる。線の外の同じ音 `ges,,,8` は G1 の位置に **♭ なし**で描かれ、紙の上では `g,,,` と読める（この小節で G1 にはまだ ♭ が付いていない）。

**LilyPond 2.26.0** も同じ絵になる（実際の音高で臨時記号を覚えるため）。なので不具合ではなく、方針の一貫性の話。
Lily# は `1aca41cd2` で「オッターヴァの線の下の臨時記号は、描いた場所で決める」ことにした。その決まりに従うと、線の外の G1 にも ♭ が要る（線の下の ♭ は G2 に付いたものだから）。

LilyPond どおりで良いという判断なら、それで構わない。その場合、OMR は紙から区別できないので、読み誤りとして残す。

**OMR への害**: seed 11 の ledger002 の 12 小節で `ges,,,8` を `g,,,8` と読む。
