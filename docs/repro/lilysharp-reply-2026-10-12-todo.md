## 2. O3 の照合（`verify`）: 0.0〜0.3 を「音が違う」ときだけにした

3 冊で数えると、照合の旗の中身は**スラー（161）・スキャンにだけある点（118、多くはスタッカート）・タイ（99）**が一番多かった（dl-scan）。音もリズムも違わない。
それを全部 0.0〜0.3 にすると、Lily# の F8 が音の誤りより先にスラーを回る。そこで:

| 差の中身 | confidence |
|---|---|
| 音符・休符・臨時記号・符幹・連桁・連符の数字（「音が違う」） | 1 記号 0.3、2〜3 は 0.2、〜8 は 0.1、それ以上 0（**案のとおり**） |
| TAB のフレットが五線の音と合わない | 0.3 |
| 小節の長さだけ（`omr verify`、lysc の LYS2001/2002） | 0.2 |
| タイだけ | 0.6 |
| スキャンにだけある点だけ（小節の長さは合っている） | 0.8 |
| スラーだけ | 0.85 |
| スキャンに何も見えない小節に、テキストが小節全体の休符を書いただけ | 0.85 |

⇒ 既定のしきい値 0.8 で、点・スラー・空の小節は `.lys` に書かれない。表の形が違ってよければこのまま、だめなら 0.0〜0.3 に戻す（1 行）。
