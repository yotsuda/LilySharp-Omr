## 1. 段をまたいだトリルの線の続きが止まる音符から始まる次の線が、1 段外へ積まれる

再現: **`docs/repro/trillspan-chained-after-break-2026-10-21.lys`**（2 小節）

```lys
section Piece {
  p1 {
    c'4 d'4 e'4 f'4@startTrillSpan | break
    g'4 a'8 b'8@stopTrillSpan@startTrillSpan c''8 b'8 a'4@stopTrillSpan |
  }
}
```

**症状**: 1 小節目の `f'4` からの線は段をまたいで 2 小節目の `b'8` で止まる。同じ `b'8` から始まる 2 本目の線の「tr」と波が、続きの波より約 1 間隔高く描かれる。
続きの波は `b'8` の手前で終わっていて、横に重なってはいない。段の切れ目がなければ（同じ音符を 1 段に書くと）、2 本は同じ高さに描かれる。

**LilyPond 2.26.0**: 2 本目の線を続きの波と同じ高さに描く。

**見立て**: 続きの部分（左が切れたトリルの線）の横の広がりか輪郭が、止まる音符の列の先まで数えられていて、次の線をその外に積んでいるのでは。

**OMR への害**: 生成譜 piano006（`out/gen-trill-s11/piano/piano006/piano006.lys`）の左手 11 小節で、押し上げられた「tr」が右手の下の声部の 16 分音符の連桁に触れ、検出器が「tr」を見ない。線が丸ごと読めない。

## 2. 観察: 続きの段の頭の「tr」

上の再現で、LilyPond 2.26.0 は 2 段目の続きの波の頭にも「tr」を刷る。Lily# は刷らない（波だけ）。
どちらが正しいかの判断はそちらに任せる。参考まで: OMR は今の Lily# の絵（続きは波だけ）を前提に読んでいる。続きにも「tr」を刷るように変えるなら、知らせてくれれば OMR 側を合わせる（続きの「tr」を新しい線の始まりと読まないように）。

## 不具合ではなかったもの（参考）

ページの最後の段の最後まで走ったトリルの線が、次のページの最初の音符で止まるとき、次のページに続きの波が描かれない（seed 11 の piano003 の 12〜13 小節）。
