# Lily# から OMR へ（2026-10-28）: Lily# のオクターブが LilyPond と同じになった

**オーナー決定（2026-10-28）**: Lily# のオクターブを、どのパート・どの楽器でも LilyPond と同じにした。互換性が変わる変更で、OMR が書く `.lys` に直接かかわる。Lily# の `master` に入ったが、まだ出荷していない（版はオーナーが決める）。

## 何が変わったか

| | 前 | 今（LilyPond と同じ） |
|---|---|---|
| `octave absolute` の裸の `c` | C4 | **C3**（`c'` が中央の C ＝ `\fixed c`） |
| relative の新しい枠（セクション・フレーズの頭） | C4 から | **F3 から**（音高を書かない `\relative { … }` と同じ） |
| `instrument` の preset | オクターブを動かした（`bass` は 3・`flute` は 5 など） | **動かさない**（どの preset でも裸の `c` は C3） |
| `part X { octave N }` | 基準を動かす | 同じ（明示のずらしとして残る） |
| オクターブ記号付きの音部記号（`treble_8`・ギター） | 書いた高さは鳴る高さの 1 オクターブ上 | **鳴る高さで書く**（LilyPond と同じ。clef の 8 が 1 オクターブ上に描く） |

例（`octave absolute`）: 中央の C は `c'`、ト音記号の第 1 線の E は `e'`、ヘ音記号の第 2 間の C は `c`、五線の上の A は `a''`。

## OMR へのお願い

1. **`.lys` を書く部分を新しい規則に合わせてほしい。** 今までの出力を新しい Lily# で開くと、多くの音が 1 オクターブ低く読まれる。
   - `octave absolute` で書いているなら、印を LilyPond と同じにする: 音名の octave が N なら `'` を N−3 個（N<3 なら `,` を 3−N 個）。
   - relative で書いているなら、各セクションの最初の音を F3 から最も近い高さとして印を付ける。
2. **パートの `octave N` は、OMR の出力でオクターブを合わせるためには使わないでほしい。** preset はもう音を動かさないので、ヘ音記号のパートにも `octave 3` は要らない。紙のとおりに印を書けば足りる。
   - 後からユーザーが `instrument bass` を書き足しても、音符は動かない。ここがこの決定の理由の一つ。
3. **ギター（`treble_8`）のパートは、鳴る高さで書いてほしい。** 紙で第 3 間の C に見える音は、`treble_8` では C4 として鳴るので `c'`。clef の `8` に合わせて 1 オクターブ下げてから書く。
4. **ベースのように「書いた音より 1 オクターブ下で鳴る」楽器**: 楽譜の上の高さ（書かれた音）のまま書けばよい。`instrument bass` が鳴りを 1 オクターブ下げる。ヘ音記号で見えたとおりに、第 2 間の C は `c`。
5. **照合（`omr verify --candidate`）で使う lysc の版。** 新しい規則の `.lys` は、新しい lysc で照合しなければ合わない。
   - Lily# の版の床（`OMR_MIN_VERSION` の逆向き、OMR が求める lysc の版）をどう持つか、決めてほしい。
   - 目印が要るなら、Lily# 側で `lysc --version --json` の `features` に足すことができる。名前を言ってほしい。

## Lily# 側で済んでいること

- MusicXML の取り込み（`LysWriter`）は、新しい規則で書く（C4 は `c'`）。
- Lily# のリポジトリにある楽譜・レッスン・テストは、すべて新しい規則に書き直した。前と同じに鳴り、同じ位置に描かれることを確かめてある。
- 旧規則の `.lys` を自動で移すコマンドは作らない（オーナー決定）。OMR が過去に書いた `.lys` は読み直すか、手で直す。

## 確かめ方

`lysc check --pitches file.lys` は、各音を描かれる高さで書き出す（例: `2:17  c  -> C3`）。紙の高さと 1 行ずつ比べられる。

詳しい規則は Lily# の `docs/GRAMMAR.md`（Octave の注）、`docs/SYNTAX_REFERENCE.md`（Octave Marks）、`CHANGELOG.md`（Octaves — BREAKING）にある。
